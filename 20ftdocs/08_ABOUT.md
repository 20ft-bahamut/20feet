# About Specification

## 1. URL

`/about`

## 2. 목적

- 20ft의 이름과 현재 정체성
- 작은 공간 / 가능성의 철학
- Founder의 개발 경험
- JUST FOR FUN

을 짧고 사람답게 설명합니다.

## 3. Hero

Eyebrow: `ABOUT 20FT`

Heading: **20ft는 작은 공간에서 시작했습니다.**

Intro:

> 20피트 남짓한 작은 공간도 아이디어와 도구가 모이면 무엇이든 시작할 수 있는 곳이 될 수 있다고 생각했습니다.

## 4. From Space to Software

Heading: **FROM SPACE TO SOFTWARE.**

Body:

> 처음의 20ft에는 물리적인 공간을 만들고, 도구를 만지고, 새로운 것을 실험한다는 생각이 있었습니다.
>
> 지금의 20ft는 같은 이름으로 웹사이트와 소프트웨어, 오픈소스와 필요한 도구를 만듭니다.
>
> 형태는 달라졌지만 직접 만들고 실험한다는 태도는 그대로입니다.

과거 카라반/카페 실패 과정은 본문 핵심으로 사용하지 않습니다.

## 5. Founder

Heading: **BUILDER BEHIND 20FT.**

Main copy:

> 20년 넘게 웹을 만들었습니다.
>
> 개발자로 시작해 서비스 기획과 프로젝트 관리, 제품 구축까지 함께 해왔습니다.
>
> 특정 기술을 과장하기보다 문제에 맞는 구조를 선택하고, 실제로 운영되는 결과물을 만드는 일을 중요하게 생각합니다.

Evidence labels:

- `20+ YEARS / WEB DEVELOPMENT`
- `DEVELOPMENT / PLANNING / PM`
- `WEB / PRODUCT / SYSTEM`

필요 시 작은 line:

> PHP를 기반으로 다양한 웹 시스템을 개발해왔고, 프로젝트에 따라 Node.js와 현대적인 Frontend 기술을 함께 사용합니다.

## 6. Just For Fun

Heading: **JUST FOR FUN.**

Body:

> 재미있는 문제를 발견하고, 직접 해결하고, 더 나은 방법을 찾는 것.
>
> 20ft가 기술을 계속 만드는 가장 단순한 이유입니다.
