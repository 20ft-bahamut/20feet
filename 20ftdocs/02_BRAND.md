# 20ft Brand

## 1. 브랜드 정의

**20ft는 작은 공간에서 웹, 소프트웨어, 도구와 아이디어를 직접 만드는 독립 Software Studio입니다.**

보조 표현: **Digital Garage**

`Digital Garage`는 개발자 장난감 사이트를 뜻하지 않습니다. 작은 공간 안에 도구와 아이디어가 모여 실제 결과물이 나오는 maker space의 디지털 버전이라는 의미입니다.

## 2. 이름의 기원

20ft라는 이름은 20피트 컨테이너라는 작은 규격의 공간에서 출발했습니다.

처음에는 빈티지 카라반을 국내 환경에 맞게 스마트 카라반으로 바꾸는 아이디어가 있었고, 온·습도 제어, 물량 모니터링, 자동 수평 조정 같은 하드웨어·소프트웨어 기술을 시도했습니다.

사업 자체는 이어지지 않았지만 `20ft`라는 이름은 남았습니다.

> **20피트 정도의 작은 공간도, 아이디어와 도구가 모이면 무엇이든 시작할 수 있는 곳이 될 수 있다.**

과거에는 물리적인 공간과 카페가 있었고, 지금은 웹과 소프트웨어를 만드는 공간이 되었습니다.

사이트에서 이 과거를 실패담이나 연혁으로 길게 설명하지 않습니다. 현재 브랜드를 이해하는 **짧은 배경**으로만 사용합니다.

## 3. 핵심 철학

### A SMALL SPACE. INFINITE POSSIBILITIES.

작은 공간이 가능성의 크기를 결정하지 않습니다.

20ft는 작지만 깊게 만들고, 필요한 것을 직접 구현합니다.

### JUST FOR FUN.

재미있는 문제를 발견하고 직접 해결하는 태도입니다.

가벼운 결과물을 만든다는 의미가 아닙니다.

> 재미있기 때문에 더 깊이 파고들고, 실제로 작동할 때까지 만드는 태도.

## 4. 브랜드 인상 목표

반드시 느껴져야 하는 것:

- 기술력이 있다
- 예쁘다
- 독창적이다
- 직접 만드는 곳 같다
- 작은 규모지만 깊이가 있다
- 일을 맡겨도 될 만큼 단단하다

느껴지면 안 되는 것:

- 스타트업 흉내
- AI 스타트업
- 흔한 SI 회사
- 광고대행사
- 개발자 포트폴리오 장난감
- 감성 카페 브랜드
- 남성 취향/맨케이브를 그대로 복원한 사이트

## 5. 현재 20ft가 만드는 범위

Top-level Services 메뉴로 상품화하지는 않지만, Portfolio와 Inquiry에서 아래 범위를 자연스럽게 보여줍니다.

- Website
- Commerce
- Web Service / SaaS
- Gnuboard 7
- Custom Software
- Admin / Internal Tool
- Integration / Automation
- Open Source / Developer Tool

AI는 필요할 때 쓰는 도구일 뿐 20ft의 브랜드 카테고리가 아닙니다.

## 6. Founder 톤

20ft는 익명의 조직처럼 꾸미지 않습니다.

20년 넘게 웹을 만들고, 개발뿐 아니라 기획·PM·제품 구축까지 수행해 온 Builder가 운영하는 작은 Studio라는 사실은 신뢰 요소입니다.

핵심:

- 20+ years in web development
- Developer / Planner / PM / Product Builder
- PHP를 기반으로 다양한 웹 시스템 경험
- 필요에 따라 Node.js, modern frontend 등 사용
- 기술 자체보다 실제 서비스 구축과 운영을 중요하게 봄

## 7. Brand Voice

- 짧고 명확함
- 과장하지 않음
- 실제로 하는 것만 말함
- 기술 용어는 필요할 때만
- “혁신”, “최고”, “압도적” 같은 광고 문구 지양
- AI를 미래/혁신의 상징처럼 사용하지 않음

좋은 예:

> 웹과 소프트웨어, 필요한 도구를 직접 만듭니다.

> 사용하는 도구가 부족하면 직접 만들기도 합니다.

> 작게 시작해도, 운영되는 구조까지 생각합니다.

피해야 할 예:

> 혁신적인 디지털 트랜스포메이션으로 비즈니스의 미래를 선도합니다.
