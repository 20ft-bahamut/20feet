## 9. 미확정 / 보고

- 퓨어폴 **담당 범위**는 게시판에 `role: ["CTO"]`(직함)만 있어 구조화된 '담당 범위' 섹션을 만들지 못했다. 직함은 '역할'로 표기했고, 나머지는 관리자 본문(목적·기능·사용자 흐름)을 그대로 보여준다. 담당 범위 자료가 보강되면 섹션을 추가할 수 있다.
- `superbify-roastery` 는 미게시(근거는 `DECISIONS.md`). 게시되면 사례 목록·서비스 상세에 자동 포함된다.
- 공개 연락처·개인정보 문구·문의 수신 설정은 여전히 배포 차단 항목(`STATUS.md`).

### 배치 변경

- `/superbify/superbify-commerce-minimal`: 문의 안내와 `쇼핑몰 제작 문의` 버튼을 **대표 화면 바로 아래**로
  옮겼다(제품 설명·제품 정보·링크보다 앞). 하단에는 `쇼핑몰 제작 안내`·`제작 사례 보기`만 남기고
  같은 안내와 버튼을 반복하지 않는다. 기술 정보와 GitHub 링크는 하단 유지.
- `/about` 이름 유래 영역: 본문이 네 문단 → 한 문단으로 줄었다. 현재 섹션 높이는
  1440px 316px / 360·390px 284px 이고, 남는 빈 높이는 0px(내용 높이와 섹션 높이 일치).
  (줄이기 전 높이는 측정하지 않았다 — 문단 수가 4 → 1 로 준 것만 확인했다.)
- `/about` 마무리 영역: 슬로건을 뺀 링크 묶음만 남아 1440px 160px / 360·390px 192px.
