# 04. 페이지별 카피와 콘텐츠

아래 문구는 구현 초안이다. 사실과 제공 범위는 `01`을 따르고, 근거 없는 약속을 추가하지 않는다. 같은 의미를 반복해서 페이지를 길게 채우지 않는다. 고객이 읽는 영역에 구현 기술이나 이 작업 지시를 노출하지 않는다.

## 공통 언어

- 홈페이지 제작 / 쇼핑몰 제작 / 맞춤형 웹프로그램 개발을 기본 용어로 사용한다.
- 커머스, SaaS, CMS, API, G7은 구체적인 필요가 있는 상세 설명에서만 사용한다.
- 버튼: ‘제작 문의하기’, ‘제작 사례 보기’, ‘홈페이지 제작 알아보기’처럼 목적을 명시한다.
- ‘혁신’, ‘가능성’, ‘최고의 솔루션’, ‘디지털 경험’만으로 서비스 가치를 설명하지 않는다.
- ‘저희 전문팀’, ‘전담 디자이너’ 등 미확인 인력을 전제하지 않는다.
- 모든 사례·이미지 설명은 실제 자료와 일치한다.

## 홈

### 첫 화면

보조표기: `이십피트 · 웹사이트 제작 및 개발`

H1: `홈페이지·쇼핑몰 제작부터\n맞춤형 웹프로그램 개발까지.`

설명: `회사와 브랜드를 소개하는 홈페이지, 상품을 판매하는 쇼핑몰, 업무에 맞춘 웹프로그램을 기획하고 개발합니다. 필요한 기능과 운영 방식을 함께 정리하는 것부터 시작합니다.`

주 버튼: `제작 문의하기` → 문의
보조 버튼: `제작 사례 보기` → 사례
안내: `기획서가 없어도 괜찮습니다. 만들고 싶은 것과 현재 상황을 알려주세요.`

개발 범위가 확인되지 않은 디자인·촬영·카피라이팅까지 ‘모두 포함’으로 확대하지 않는다. 첫 화면 비주얼은 실제 화면을 사용한다.

### 서비스

제목: `어떤 제작이 필요하신가요?`

홈페이지 제작: `회사와 서비스, 브랜드를 소개하는 웹사이트를 만듭니다. 새 홈페이지 제작이나 기존 사이트 개편을 상담할 수 있습니다.`

쇼핑몰 제작: `상품을 살펴보고 주문하는 고객의 흐름과, 상품·주문을 관리하는 운영자의 흐름을 함께 고려합니다.`

맞춤형 웹프로그램 개발: `고객·예약·계약·작업 일정처럼 업무에 필요한 정보를 웹에서 관리할 수 있도록 설계하고 개발합니다.`

예시는 의뢰 가능한 분야의 설명이다. 실제 납품 실적이나 모든 기능의 기본 포함을 뜻하지 않도록 상세에서 범위를 구분한다.

### 대표 사례

제목: `실제로 만든 화면과 기능을 확인하세요.`
설명: `고객 프로젝트와 자체 제작 데모를 구분해 소개합니다.`

퓨어폴: `매장·계약·현장 작업·리포트를 연결한 업무 관리 시스템`.
Roastery: `상품 탐색부터 주문 화면까지 구성한 브랜드 쇼핑몰 데모`.
Minimal: 검증된 현재 화면과 설명을 확인한 후 한 줄로 요약한다.

### 담당자 경험

제목: `20년 이상 웹을 만들며, 기획과 개발을 함께해왔습니다.`
설명: `웹사이트 제작부터 서비스 기획, 업무 시스템 개발과 운영까지 경험해왔습니다. 필요한 기능이 실제 사용 흐름에 맞는지 함께 살펴봅니다.`
링크: `이십피트 소개 보기`.
경력 수치는 기존 소개에 근거한다. 검증된 경력 타임라인이 있으면 연결한다.

### 절차 요약

제목: `상담부터 오픈까지, 이렇게 진행합니다.`
- 상담: 현재 상황과 만들고 싶은 것을 듣습니다.
- 범위·견적 협의: 필요한 기능, 제공 자료, 일정과 비용을 협의합니다.
- 제작·확인: 합의한 범위에 따라 작업하고 확인할 내용을 공유합니다.
- 검수·오픈: 결과물을 확인하고 오픈과 이후 관리 범위를 정리합니다.

실제 운영 방식과 다르면 조정하고 결정 기록에 남긴다. 계약상 보장으로 오인할 구체적인 무료 횟수·기한은 추가하지 않는다.

### 마지막 문의

제목: `필요한 웹사이트, 어떤 모습인지 이야기해주세요.`
설명: `새로 만들고 싶은 것, 현재 불편한 점, 참고 사이트 중 편한 것부터 알려주세요.`
버튼: `제작 문의하기`.

## 제작 서비스 목록

H1: `필요한 목적에 맞춰 웹사이트를 제작합니다.`
설명: `홈페이지, 쇼핑몰, 맞춤형 웹프로그램 중 필요한 분야를 살펴보세요. 여러 기능을 함께 구성해야 하는 경우에도 문의할 수 있습니다.`
각 서비스는 대상 상황·예시 결과물·관련 사례·상세 링크를 가진다. 가격표를 임의로 만들지 않는다.

## 홈페이지 제작 상세

H1: `회사와 브랜드를 소개하는 홈페이지 제작`
설명: `어떤 정보를 누구에게 보여줄지 정리하고, 방문자가 서비스와 문의 방법을 찾기 쉽게 구성합니다.`

섹션:
1. 이런 의뢰를 상담합니다: 회사 소개, 브랜드·제품 소개, 기존 홈페이지 개편.
2. 함께 정할 내용: 페이지 구성, 필요한 자료, 문의 기능, 관리·수정 방법, 모바일 화면.
3. 확인할 결과물: 검증된 홈페이지 작업만 사용. 없으면 현재 이십피트 사이트를 ‘자체 사이트’로 명시하거나 이미지 없는 범위 안내로 구성.
4. 상담에 도움이 되는 정보: 제작 목적, 참고 사이트, 필요한 페이지, 희망 일정. 모두 사전 필수 준비물로 강요하지 않는다.
5. 홈페이지 제작 문의 → 문의 유형 선택.

## 쇼핑몰 제작 상세

H1: `판매와 운영 흐름을 고려한 쇼핑몰 제작`
설명: `브랜드와 상품을 보여주는 화면부터 주문 과정, 운영에 필요한 기능까지 범위를 정리합니다.`

섹션:
1. 고객 화면: 상품 탐색, 상세, 장바구니, 주문 등 검증 가능한 작업 예시.
2. 운영 범위 협의: 상품·주문 관리, 배송·결제 연동 등 프로젝트별 확인 사항. 결제 계약과 실제 연동을 기본 제공으로 약속하지 않는다.
3. Roastery·Minimal의 실제 화면, ‘자체 제작 데모’ 배지, 데모 보기.
4. 기존 기능 활용과 맞춤 개발은 요구사항을 보고 결정한다는 설명.
5. 쇼핑몰 제작 문의.

## 웹프로그램 상세

H1: `업무에 맞춰 설계하는 웹프로그램 개발`
설명: `여러 파일과 수작업으로 나뉜 업무를 살펴보고, 필요한 데이터와 사용자별 기능을 연결합니다.`

섹션:
1. 상담 예시: 고객·계약 관리, 예약·작업 일정, 관리자, 회원 서비스, 기존 시스템 기능 개선.
2. 설계할 내용: 사용자별 역할, 입력과 조회, 업무 순서, 외부 시스템 연결 필요성.
3. 퓨어폴 사례: 매장·계약·케어 일정·리포트 연결과 실제 담당 범위.
4. 첫 상담: 현재 업무를 설명해도 된다는 안내. 확정되지 않은 요구를 모두 구현 가능하다고 약속하지 않는다.
5. 웹프로그램 개발 문의.

## 진행 안내와 FAQ

H1: `문의부터 제작까지의 진행 안내`

절차마다 ‘고객이 알려줄 것 / 이십피트가 정리할 것 / 다음 단계’를 짧게 설명한다. 문의를 계약이나 발주 확정으로 표현하지 않는다.

FAQ 기본안:
- Q. 기획서가 없어도 문의할 수 있나요? A. 가능합니다. 제작 목적과 필요한 내용, 현재 불편한 점부터 알려주세요.
- Q. 비용과 기간은 어떻게 정하나요? A. 페이지 구성, 기능, 연동 범위와 제공 자료 등에 따라 달라집니다. 문의 내용을 바탕으로 제작 범위를 먼저 협의합니다.
- Q. 기존 사이트 개선도 상담할 수 있나요? A. 현재 사이트 주소와 변경하고 싶은 내용을 알려주세요. 기존 환경과 소스 접근 가능 여부 등을 확인해 작업 범위를 검토합니다.
- Q. 오픈 후 관리도 포함되나요? A. 관리와 유지보수 범위는 제작 내용과 운영 환경에 따라 별도로 협의합니다.

고객에게 약속하기 전 실제 사업 운영 방침과 충돌하는 내용이 있는지 확인한다.

## 소개·제품·문의

소개는 `06`, 문의는 `07`의 상세 기준을 따른다. 제품 상세는 기존 기술 문서를 보존한다. 사이트 전역의 메타 제목은 각 페이지 내용에 맞춰 ‘홈페이지 제작 | 이십피트’와 같은 명확한 형태로 작성한다. 실제 존재하지 않는 지역·수상·실적 키워드를 추가하지 않는다.
