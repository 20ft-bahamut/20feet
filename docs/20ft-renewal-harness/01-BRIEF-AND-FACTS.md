# 01. 사업 목표와 사실 기준

## 확정된 사용자 의도

- 20ft는 홈페이지·이커머스·웹프로그램 외주를 받으려는 사이트다.
- 사업 우선순위: 외주 → 개발자 개인브랜드 → SuperBify.
- 일반 고객이 즉시 업종과 의뢰 가능 범위를 이해해야 한다.
- 기존 사이트의 추상적 문구와 정보구조를 전면적으로 재검토한다.
- Claude Code로 만든 기존 사이트를 실제 소스에 맞게 개편한다.
- 사용자가 그누보드 G7 기반임을 확인했다. G7 유지와 코어 비수정을 기본 제약으로 적용한다. 정확한 설치 버전과 확장 API는 저장소에서 확인한다.
- 사용자가 직접 만든 `20ft Studio` 사용자 템플릿의 개편이다. 신규 템플릿 제작이 기본 목표가 아니다.

## 사용자 제공 관리자 화면에서 확인한 내용

- 템플릿 관리의 유저 템플릿 탭에서 `20ft Studio`가 현재 활성 상태.
- 표시 버전: `20ft Studio v0.2.0`, 하단 G7 `v7.0.8`.
- 설명: `20ft 공식 Website User Template (Portfolio / SuperBify / Project Inquiry)`.
- 작성자: 20ft. 의존성 표시: `20ft 콘텐츠`, `게시판`.
- `코드 편집`, `레이아웃 편집` 버튼이 존재.
- Basic은 비활성, SuperBify Commerce Minimal은 미설치로 표시.

이 관찰은 현재 활성 템플릿과 패키지 관계를 찾기 위한 단서다. 디렉터리명, 모듈 식별자, 저장 형식, 편집 기능의 실제 범위와 최신 버전은 소스로 확인해야 한다. 관리자 계정 정보는 작업 문서나 결과물에 복사하지 않는다.

## 관찰된 기존 사이트: 2026-09-16

- 메인: ‘작은 공간에서, 큰 가능성을 만듭니다’가 가장 큰 제목. 흐릿한 로고가 주요 시각 요소.
- 메뉴: Portfolio, SuperBify, About, 프로젝트 문의.
- 서비스 분류: WEB, COMMERCE, SOFTWARE, GNUBOARD 7. 제작물과 기술 기반의 분류가 혼재.
- 공개 포트폴리오 목록에서 퓨어폴 SaaS 한 건 확인.
- 퓨어폴: 매장·계약·케어 일정·위생 데이터·리포트·안심 QR을 연결한 B2B SaaS로 소개됨. Client는 케이영산업개발, 기술은 svelte·CI4, What We Did는 CTO로 표기됨.
- 소개 페이지: 20년 이상 웹 개발, 기획·프로젝트 관리·제품 구축 경험, PHP 기반과 프로젝트별 Node.js·프런트엔드 기술 활용을 설명함.
- SuperBify: Commerce Compat 플러그인, Commerce Minimal 템플릿, Commerce Roastery 템플릿이 노출됨.
- Roastery: DAYOFF COFFEE라는 가상 브랜드의 데모. 실제 고객 프로젝트로 표시하면 안 됨.
- 문의 페이지: ‘온라인 문의 접수 기능 준비 중’, 입력과 전송 비활성화. 해당 페이지에서 대체 연락 경로를 확인하지 못함.

위 내용은 사이트의 자기소개와 공개 상태를 확인한 것이며 독립적인 경력 검증 또는 코드 검증이 아니다. 제품 버전은 저장소와 최신 공개 정보를 확인하기 전 고정하지 않는다.

## 활용 가능한 차별점

단순 화면 제작을 넘어 서비스 기획·개발·업무 흐름 설계 경험을 연결해 설명한다. 퓨어폴은 구체적인 시스템 구축 역량, SuperBify는 실제 제품 제작과 공개 경험의 근거로 사용한다. 다만 개인 기여 범위와 고객 프로젝트 권리를 확인한 뒤 표현한다.

## 미확정: 추정 금지

- 가격, 최소 계약 금액, 평균 납기, 상담 회신 시간.
- 실제 조직 규모, 디자이너·개발자 구성, 상시 협력 인력.
- 디자인·콘텐츠 제작·촬영·호스팅·도메인 등 계약 포함 범위.
- 수정 횟수, 무상 보수 기간, 상시 장애 대응, 소스 인도 조건.
- 연락처, 수신 이메일, 사업자정보, 문의 보관 기간과 개인정보 처리 조건.
- 공개 가능한 기존 고객·작업, 담당 범위, 성과 수치, 추천사.

진행 중 이 정보가 필요하면 기존 승인된 설정/문서에서 찾는다. 없으면 질문하거나 해당 약속을 생략한다. ‘24시간 이내’, ‘100%’, ‘무제한’, ‘최저가’, ‘무료’, ‘원스톱 전담팀’ 같은 표현을 관성적으로 추가하지 않는다.

## 범위 밖

SuperBify 제품 자체의 기능 개발, 결제 쇼핑몰 신설, 신규 브랜드명·로고 개발, CRM 전면 교체, 대규모 CMS 이전은 이번 작업의 기본 범위가 아니다. 외주 홈페이지 개편에 필요한 연결과 콘텐츠 정돈만 한다.
