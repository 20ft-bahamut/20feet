# 이십피트 외주 수주 중심 홈페이지 개편 하네스

이 패키지는 Claude Code에 전달하는 작업 명세와 실행 지침입니다. 실제 사이트 소스나 완성된 웹사이트가 들어 있는 패키지는 아닙니다.

## 사용 방법

1. ZIP을 풀어 실제 20ft 홈페이지 저장소에 `20ft-renewal-harness/` 폴더로 넣습니다. 저장소 루트의 기존 AGENTS.md나 CLAUDE.md를 덮어쓰지 않습니다.
2. 해당 저장소에서 Claude Code를 실행합니다.
3. `START-HERE.md`의 시작 프롬프트를 복사해 전달합니다.
4. Claude Code가 이 패키지와 기존 소스를 읽고 분석 → 명세 보정 → 구현 → 검증을 진행하게 합니다.
5. 결과는 로컬 또는 저장소에 이미 마련된 비공개 프리뷰에서 확인합니다. 운영 배포와 외부 서비스의 유료·계정 변경은 별도 승인 대상입니다.

## 목표

방문자가 첫 화면에서 홈페이지·쇼핑몰·맞춤형 웹프로그램 제작을 의뢰할 수 있는 곳임을 이해하고, 사례와 담당자의 경험을 확인한 뒤 실제 문의할 수 있게 개편합니다.

우선순위는 반드시 **외주 수주 > 개발자 개인브랜드 > SuperBify**입니다. 브랜드 감성만 바꾸거나 기존 페이지 제목만 바꾸는 작업이 아닙니다. IA, 콘텐츠, 사례 설명, 시각적 우선순위, 문의 동선을 함께 개편합니다.

## 필수 기술 제약: 그누보드 G7

사용자가 이 사이트는 **그누보드 G7 기반**이라고 확인했습니다. G7을 유지하며 현 저장소의 템플릿·플러그인·콘텐츠·관리자 구조 안에서 개편합니다. G7 코어 비수정을 원칙으로 하고, 별도 Next.js/React 사이트 등으로 재구축하지 않습니다. G7이라는 이름만 보고 그누보드 5의 디렉터리·훅·API를 적용해서도 안 됩니다. `11-G7-CONSTRAINTS.md`를 반드시 읽습니다.

수정 대상은 기존 **`20ft Studio` 사용자 템플릿**입니다. 사용자 제공 관리자 화면에는 활성 `20ft Studio v0.2.0`, G7 `v7.0.8`, 의존성 `20ft 콘텐츠`·`게시판`, 코드 편집·레이아웃 편집 기능이 보입니다. 버전은 화면 관찰값이며 실제 소스와 대조합니다. 기존 템플릿을 개편하고, 별도 신규 템플릿을 기본 해법으로 만들지 않습니다.

## 패키지의 한계

2026-09-16 공개 사이트를 브라우저에서 확인한 관찰과 사용자의 우선순위에 기반합니다. 저장소와 관리자, 실제 운영 통계, 문의 수신 환경은 검사하지 않았습니다. 문서의 현재 상태 설명은 출발점이며 실제 소스와 다르면 근거를 남겨 갱신합니다.

가격, 납기, 수정 횟수, 무상 유지보수, 응답 시간, 조직 규모와 고객 성과를 이 패키지가 확정하지 않습니다. 확인되지 않은 약속을 사이트에 게시하지 않습니다.
