# Changelog

이 언어팩의 모든 주요 변경사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를 따르며,
[Semantic Versioning](https://semver.org/lang/ko/)을 준수합니다.

## [1.0.3] - 2026-07-22

### Added

- 해외결제(CBT) 편의점·가상계좌 입금 시뮬레이션 안내 문구 일본어 번역 추가.

## [1.0.2] - 2026-07-22

### Added

- 해외결제(CBT) 연결 진단 결과 안내의 일본어 번역을 추가했습니다. 일본어 로케일에서 안내 대신 내부 식별자가 보이던 문제가 해소됩니다.

## [1.0.1] - 2026-07-16

### Added

- 주문 설정 화면의 KG 이니시스 테스트모드 경고(`kginicis_test_mode_status`, `test_mode_settings_warning_*`) 일본어 번역 추가 — 테스트결제 상태 안내와 실결제 설정 이동 버튼이 일본어 로케일에서 자연스럽게 표시됩니다.

## [1.0.0] - 2026-07-01

### Added

- 라이브 일본 결제(CBT) 설정 검증 안내(`settings_validation.*` — 일본 CBT 해시키·MID·가맹점명·연락처 입력 필수 안내와 샘플 값 교체 안내) 일본어 번역 추가 — 라이브 모드 일본 결제 설정 입력 검증 실패 안내가 일본어 로케일에서 자연스럽게 표시됩니다.
